# DolphinDex

Децентрализованная биржа (DEX), разработанная для экосистемы **XRP Ledger (XRPL)** с использованием **TypeScript** и **Vite**.

## Технологии

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- XRPL
- TradingView Charting Library

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Возможности

- 📈 Торговый терминал с интеграцией **TradingView**
- 💱 Децентрализованная биржа на **XRPL**
- 💧 AMM (Automated Market Maker)
- 🌾 Фарминг (Yield Farming)
- 🚀 Мемпад для запуска токенов
- 🎮 Мини-игры:
  - Шахматы
  - Шашки
  - Дурак
- 👛 Подключение XRPL-кошельков и работа с цифровыми активами
